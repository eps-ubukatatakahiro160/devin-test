# WSL & Git クイズ

純粋な HTML / CSS / JavaScript で作った、WSL と Git に関する単一選択式クイズ（全10問）です。

## 使い方

`index.html` をブラウザで開くだけで動作します（ビルド・サーバー不要）。

## 機能

- 4択の単一選択式 × 10問（WSL 5問、Git 5問）
- 回答直後に正誤判定と解説を表示（正解は緑、誤答は赤）
- 最終スコア（正解数・正答率）と全問の振り返りを表示
- 「もう一度」で最初から再挑戦

## ファイル構成

```
index.html        画面構成（スタート / 問題 / 結果）
css/style.css     スタイル
js/questions.js   問題データ
js/quiz.js        クイズのロジックと描画
tests/            ロジックのユニットテスト
```

## テスト

```
node --test
```
